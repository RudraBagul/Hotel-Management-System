## 📌 Project Overview

This project is a Python-based Hotel Management System developed using
Object-Oriented Programming (OOP) concepts.

The system replicates the physical food-ordering process through an
interactive machine. The machine communicates with customers using
simple binary inputs such as **Yes/No** and performs the corresponding
operations based on their responses.

The system also handles invalid inputs and provides an interactive
step-by-step ordering process.

## ⚙️ Key Features

- 🍴 Interactive food ordering

- ✅ Invalid input handling
